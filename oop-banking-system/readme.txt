# Mini Banking System (Python OOP)

## Project Title
Mini Banking System using Python Object Oriented Programming

## Description
This project simulates a simple banking backend system using Python OOP concepts. 
It supports opening accounts, deposits, withdrawals, transfers between accounts, and transaction history.

Different account types are implemented using inheritance and polymorphism.

## Features
- Open Savings Account
- Open Current Account
- Deposit money
- Withdraw money
- Transfer between accounts
- View transaction history
- Overdraft support for Current Accounts

## OOP Concepts Used
- **Encapsulation** – Account balance is stored as a private attribute.
- **Inheritance** – SavingsAccount and CurrentAccount inherit from the base Account class.
- **Polymorphism** – Withdraw behavior is different for each account type.
- **Abstraction** – Account class defines the common interface.
- **Separation of Concerns** – Bank handles accounts while CLI handles user interaction.
